Welcome to my Keypad!

This is the project that I made for the 3rd week of the Hack Club Half-Life program. 
This is what they had a the beginner project, but a made a couple of modifications to make it my own!

One of the major changes I made was adding more keys so that on mine there is a while octave of notes to choose from instead of only 7. 

I put the "This is NOT a trumpet" message on the board because I play the trumpet, and I needed a way to not get confused on which instrument I was playing. 

I also added a whole bunch of buttons to keyboard that can be configured in software to do a whole bunch of different things!
